# 관리자 웹 실제 태블릿 테스트 체크리스트

- 프로젝트: 분식집 키오스크 관리자 웹
- 작성일: 2026-08-10
- 관리자 접속 주소: `http://<개발PC-IP>:3000/adminlogin`
- 백엔드 주소: `http://<개발PC-IP>:8080`
- 테스트 기기: **\*\*\*\***\_\_\_\_**\*\*\*\***
- OS / 버전: **\*\*\*\***\_\_\_\_**\*\*\*\***
- 브라우저 / 버전: **\*\*\*\***\_\_\_\_**\*\*\*\***
- 테스트 담당자: 강민준

## 결과 기준

- 통과: 예상 결과와 동일하게 동작
- 실패: 오류가 발생하거나 예상 결과와 다르게 동작
- 미실시: 실제 태블릿에서 아직 확인하지 않음

## 사전 조건

- 태블릿과 개발 PC가 동일한 Wi-Fi에 연결되어 있어야 한다.
- 관리자 프론트엔드와 백엔드 서버가 실행 중이어야 한다.
- Windows 방화벽에서 프론트엔드 포트 `3000`과 백엔드 포트 `8080`의 접근이 가능해야 한다.
- 태블릿 브라우저에서 관리자 로그인 주소가 열려야 한다.
